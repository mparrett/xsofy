The procedural title generator handed us “Caverns of Dependency Hell” before we had typed a single command. We laughed. Then we typed our first command and it was wrong, and the joke became the day.

Floor I ᚠ

Cartography — /init, the first lantern

Twenty-three .lg files in xsofy/ and six design specs in docs/. Read enough to know the shape: a single immutable world map threaded through pure functions, a byte-array terrain layered with sparse-effect maps, and a spell engine that compiles rune sequences to s-expressions and then literally evaluates them.

Wrote a CLAUDE.md that future sessions will actually read — runtime, commands, the byte-array-plus-sparse-map performance contract, the module map, and a pointer to the design docs.

CLAUDE.md is in .gitignore alongside AGENTS.md, .claude/, and friends — a project convention we left alone. The file lives locally; it does not ship.

Floor II ᚦ

Staking the ground — project memory, three empty ledgers

Scaffolded docs/project_notes/ with three files — bugs, decisions, key facts — plus inboxes for incoming and archived tickets. Empty, but waiting. The point is the next surprise has a home.

$ git commit -m "docs: initialize project memory notes" [expmt/kaiju 9221674] 3 files changed, 40 insertions(+)
Floor III ᛟ

A binding rune — never push this repo

One inscription, persistent across sessions: this is a third-party repo. Commits stay local; nothing leaves the machine. Future me will read this before reaching for git push.

Saved to ~/.claude/projects/.../memory/feedback_no_push.md, indexed in MEMORY.md. Auto-loaded on every future session in this working directory.

Floor IV ᚱ

Forge the binary — summoning let-go

Neither lg nor let-go on the path. README recommends Homebrew. Tapped nooga/let-go, installed 1.7.4, and the binary lands as lg only — both names refer to the same executable.

As a cheap sanity check before the WASM build, compiled the whole source to bytecode. Every namespace parsed, every macro expanded, every symbol resolved.

$ lg -c main.lgb main.lg — exit 0 · main.lgb 423 KB
Floor V ᛏ

The actual dependency hell — Go 1.19 versus a go.mod from the future

Asked for the WASM build. The compiler shells out to go mod tidy, which read a go.mod requiring 1.26 and met a local Go of 1.19.1. The error was uncannily on-brand:

resolving dependencies... go: go.mod file indicates go 1.26, but maximum version supported by tidy is 1.19 error: go mod tidy: exit status 1

Upgraded Go 1.19.1 → 1.26.3 through brew, re-ran the build, and the WASM pipeline produced dist/index.html — 6.3 MB, self-contained, the exact artifact CI publishes to GitHub Pages on every merge to main.

Floor VI ᛇ

First descent — Playwright in the dungeon

Served dist/ on port 8000 and drove a headless Chromium at it. The COI service worker installed on first load; cross-origin isolation came up on the reload; SharedArrayBuffer showed up where the WASM runtime expected it.

The title screen rolled Caverns of Dependency Hell — the run had named itself before we even arrived. Space advanced past the title; we landed on floor 1 with a quest to retrieve the Bucket of Your Cousin, a dagger doing 2–4, and two kobolds and a goblin in line-of-sight.

We walked into the fight, took four damage, and never reproduced the bail the user saw in their real browser. Tomorrow, with more time and a better idea of where to point the probe.
